01 · Les bases

Déclarations et variables

En Kotlin, on déclare des variables avec var.

Avec le type explicite

var age: Int = 25
var nom: String = "Alice"
var moyenne: Double = 20.0
var uneLettre: Char = 'A'
var isAdmis: Boolean = true

Les variables de type Char doivent être entre apostrophes '' et pas entre guillemets "", sinon elles seront considérées comme des chaînes de caractères String.

Avec inférence de type

Quand la valeur est connue à l'initialisation, il n'y a pas besoin de déclarer le type : le compilateur le déduit tout seul.

var age = 25
var nom = "Alice"
var moyenne = 20.0
var uneLettre = 'A'
var isAdmis = true
02 · Immuable

Constantes

Les constantes sont déclarées avec val et ne peuvent pas changer de valeur.

val PI = 3.14159
val NOM_ENTREPRISE = "Ma Société"
03 · Chaînes

Concaténation de chaînes

On peut concaténer des chaînes avec + ou utiliser l'interpolation de chaînes avec $.

val prenom: String = "Alice"
val age: Int = 25
println("Bonjour, je m'appelle $prenom et j'ai $age ans.")
04 · Réutiliser

Fonctions

Les fonctions se déclarent avec fun, et peuvent avoir des paramètres et retourner des valeurs.

fun addition(a: Int, b: Int): Int {
    return a + b
}

println(addition(5, 7)) // Affiche 12
05 · Objets

Classes

Une classe est un modèle pour créer des objets. Elle peut contenir des propriétés et des méthodes.

class Personne(val nom: String, var age: Int) {
    fun sePresenter() {
        println("Bonjour, je m'appelle $nom et j'ai $age ans.")
    }
}

val alice = Personne("Alice", 25)
alice.sePresenter()
06 · Boîte à outils

Fonctions intégrées utiles

println()

println() affiche un texte ou une valeur à l'écran avec un retour à la ligne.

println("Bonjour Kotlin")
// Affiche : Bonjour Kotlin

print()

print() affiche un texte ou une valeur sans retour à la ligne. 

print("Bonjour ")
print("Kotlin")
// Affiche : Bonjour Kotlin

readLine()

readLine() lit une entrée utilisateur depuis la console et retourne une chaîne de caractères (String?).

val nom = readLine()
println(nom)

toInt() ou toIntOrNull()

toInt() convertit une chaîne de caractères en nombre entier (Int). Il sert surtout quand la valeur vient d'un readLine() par exemple.

val nombre = "42".toInt()
println(nombre + 1) // Affiche : 43

On passe la valeur à la fonction "42".toInt(), alors que dans d'autres langages on aurait écrit toInt("42").

toDouble()

toDouble() convertit une chaîne de caractères en nombre décimal (Double).

val valeur = "3.14".toDouble()
println(valeur * 2) // Affiche : 6.28

listOf()

listOf() crée une liste immuable (non modifiable).

val fruits = listOf("Pomme", "Banane")
println(fruits)

mutableListOf()

mutableListOf() crée une liste modifiable.

val fruits = mutableListOf("Pomme", "Banane")
fruits.add("Orange")
println(fruits) // [Pomme, Banane, Orange]

replace("\\s+".toRegex(), "")

replace("\\s+".toRegex(), "") retire les espaces d'une chaîne de caractères.

val nom = readln().replace("\\s+".toRegex(), "")
Une syntaxe concise, des idées simples

Le bon objectif n'est pas de mémoriser chaque fonction.

Il faut comprendre les briques de base : variables, fonctions, classes. Une fois ces mécanismes acquis, les fonctions intégrées de Kotlin s'apprennent au fil des besoins, une par une.
