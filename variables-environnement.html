01 · Les bases

C'est quoi une variable d'environnement ?

Une variable d'environnement est une information stockée au niveau du système d'exploitation, que n'importe quel programme peut lire. Elle sert par exemple à indiquer où trouver certains outils, ou à configurer un comportement sans toucher au code.

Exemples courants

  • PATH : liste des dossiers où Windows cherche les programmes exécutables.
  • JAVA_HOME : emplacement de l'installation de Java.
  • TEMP / TMP : dossier des fichiers temporaires.

Pourquoi s'en servir avec PHP

Sans configuration, Windows ne sait pas où se trouve php.exe. Il faut soit taper le chemin complet à chaque fois, soit - plus pratique - ajouter le dossier de PHP au PATH une bonne fois pour toutes.

Prérequis : avoir déjà téléchargé et décompressé PHP quelque part sur le disque, par exemple dans C:\php. Ce guide part de cet exemple de chemin.
02 · PATH

Le PATH, à quoi ça sert

Quand tu tapes une commande dans l'invite de commandes (comme php), Windows regarde dans chacun des dossiers listés dans le PATH, dans l'ordre, jusqu'à trouver un programme portant ce nom.

Sans PHP dans le PATH

C:\Users\toi> php -v
'php' n'est pas reconnu en tant que commande interne
ou externe, un programme exécutable ou un fichier de commandes.

C'est le message classique qui indique que Windows ne trouve pas php.exe dans aucun des dossiers du PATH.

03 · Étapes

Ajouter PHP au PATH sur Windows

On suppose que PHP est décompressé dans C:\php (adapte le chemin si le tien est différent).

1

Ouvrir les variables d'environnement

Clique sur le menu Démarrer, tape variables d'environnement et ouvre « Modifier les variables d'environnement système ».

2

Ouvrir la fenêtre des variables

Dans la fenêtre « Propriétés système » qui s'ouvre, clique sur le bouton « Variables d'environnement… » en bas.

3

Sélectionner la variable Path

Dans la section « Variables utilisateur » (ou « Variables système » pour que ce soit valable pour tous les comptes), sélectionne la ligne Path puis clique sur « Modifier… ».

4

Ajouter le dossier de PHP

Clique sur « Nouveau » et colle le chemin du dossier contenant php.exe (souvent dans le dossier "bin") :

C:php\bin\
5

Valider et redémarrer le terminal ou votre console ou interprète de commandes (cmd)

Clique sur « OK » sur chacune des fenêtres ouvertes. Ferme ensuite tout invite de commandes déjà ouvert et rouvre-en un nouveau : le PATH n'est relu qu'à l'ouverture d'un nouveau terminal.

Attention : ne supprime pas le contenu existant de la variable Path. On vient seulement en ajouter un nouveau, jamais remplacer les autres.
04 · Vérification

Vérifier que ça fonctionne

Ouvre un nouveau terminal (cmd ou powershell) et tape :

C:\Users\toi> php -v

PHP 8.3.0 (cli) (built: ...)
Copyright (c) The PHP Group
Zend Engine v4.3.0, Copyright (c) Zend Technologies

Si la version de PHP s'affiche, c'est gagné : la commande php est maintenant reconnue depuis n'importe quel dossier.

05 · Exécuter

Lancer un script PHP depuis le cmd

Place-toi (avec cd) dans le dossier qui contient ton fichier PHP, puis exécute-le avec la commande php suivie du nom du fichier.

C:\Users\toi> cd C:\mon-projet
C:\mon-projet> php test.php

Bonjour depuis PHP !

Cette commande exécute le script test.php directement, comme le ferait un script en ligne de commande - sans passer par un navigateur.

06 · Serveur local

Lancer un serveur de développement PHP

PHP intègre un mini serveur web, pratique pour tester un site sans installer Apache ou Nginx. On le lance avec l'option -S suivie d'une adresse et d'un port.

C:\mon-projet> php -S localhost:8000

[Sun Sep 12 10:00:00 2026] PHP 8.3.0 Development Server
(http://localhost:8000) started

Il suffit ensuite d'ouvrir http://localhost:8000 dans le navigateur. Le serveur sert les fichiers du dossier courant (celui où la commande a été lancée). Pour l'arrêter : Ctrl + C dans le terminal.

Le port 8000 n'a rien d'obligatoire : n'importe quel port libre fonctionne, par exemple php -S localhost:8080 ou php -S localhost:3000.

07 · À retenir

Erreurs fréquentes

  • « php n'est pas reconnu » : le PATH n'a pas été mis à jour, ou le terminal n'a pas été rouvert après la modification.
  • Mauvais chemin ajouté : vérifie que le dossier ajouté au PATH contient bien directement php.exe, et pas un sous-dossier ou un dossier parent.
  • Port déjà utilisé avec php -S : choisis un autre numéro de port, par exemple 8001 à la place de 8000.
  • Plusieurs versions de PHP installées : si php -v affiche une version inattendue, une autre installation de PHP est peut-être placée avant la tienne dans le PATH.
Une variable, beaucoup de confort

Le principe est le même pour n'importe quel outil.

Ce qui vaut pour PHP vaut pour Node.js, Python, Git ou n'importe quel exécutable : ajouter son dossier d'installation au PATH permet de le lancer depuis n'importe où dans le terminal, sans jamais retaper le chemin complet.
