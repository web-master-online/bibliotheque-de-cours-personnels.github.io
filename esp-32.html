01 · Les bases

Une broche, c'est quoi exactement ?

Une broche (ou pin en anglais) est un point de contact physique sur un microcontrôleur. Certaines servent à l'alimentation, d'autres à mesurer une tension, et d'autres encore sont polyvalentes et programmables.

Les grandes familles de broches

  • GND : la masse, référence commune du circuit.
  • 3V3 : alimentation à 3,3 volts.
  • VP / VN : mesure d'une tension analogique.
  • GPIO : entrée/sortie numérique programmable.
  • RX / TX : communication série (UART).

La règle d'or à retenir

Toutes les broches partagent une même référence : le GND. Sans masse commune entre les modules connectés, aucune mesure ni aucun signal n'est fiable.

GND commun obligatoire
Important : le nombre et le nom exact des broches dépendent du modèle de microcontrôleur. Cette page rassemble le socle commun que l'on retrouve, sous une forme ou une autre, sur la plupart des cartes de développement.
02 · Masse

GND (la masse)

La broche GND représente la masse du circuit. On peut la comparer à la terre, car c'est le point de référence pour toutes les tensions et le retour du courant : une masse n'est pas reliée à la terre physique mais agit comme cette dernière.

Unité : Volt (V)

À retenir

Le GND doit toujours être commun entre tous les modules connectés, sinon les mesures et les signaux échangés n'ont plus de référence fiable.

03 · Alimentation

3V3

La broche 3V3 fournit une tension de 3,3 volts. Elle sert à alimenter certains modules ou capteurs.

Unité : Volt (V)

À retenir

Vérifie toujours la tension d'alimentation attendue par le module que tu connectes : brancher un composant prévu pour 5 V sur une sortie 3V3 (ou l'inverse) peut l'endommager ou l'empêcher de fonctionner.

04 · Mesure

VP / VN

Les broches VP et VN servent à mesurer une tension électrique. Le microcontrôleur regarde combien de volts arrivent sur ces broches et transforme cette information en une valeur utilisable par le programme.

Unité : Volt (V)

À quoi ça sert

On les utilise par exemple pour lire un potentiomètre, un capteur ou toute tension qui peut varier. Ces broches ne fournissent pas de courant et ne servent pas à alimenter un composant.

Un potentiomètre : c'est un bouton que tu tournes (ou un curseur que tu fais glisser) pour faire varier une valeur.

05 · Polyvalent

GPIO (General Purpose Input/Output)

Les GPIO sont des broches programmables pouvant servir d'entrée ou de sortie numérique.

Fonctions possibles

  • Input : lecture d'un signal externe (0 ou 1 logique)
  • Output : envoi d'un signal 0 ou 1 logique vers un composant
  • PWM : modulation de largeur d'impulsion, pour contrôler moteur ou LED
  • I2C / SPI : communication série avec d'autres modules
06 · Série

RX / TX

Ces broches sont utilisées pour la communication série (UART).

Rôle de chaque broche

  • TX : transmission de données depuis le microcontrôleur
  • RX : réception de données vers le microcontrôleur
  • Unité : Volt (V) logique (0 ou 3,3/5 selon le système)
07 · Bonnes pratiques

Notes générales

  • Respecter toujours la tension maximale des GPIO pour éviter de les griller.
  • Le GND doit toujours être commun entre tous les modules connectés.
  • Les broches analogiques (VP/VN) sont sensibles au bruit, utiliser des filtres si nécessaire.
Peu de broches, beaucoup de possibilités

Le bon objectif n'est pas de mémoriser chaque broche.

Il faut comprendre le rôle de chaque famille : alimenter, référencer, mesurer, échanger. Une fois ces rôles clairs, s'adapter à la disposition exacte d'une nouvelle carte devient beaucoup plus simple.
