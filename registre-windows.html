Ajouter tes propres commandes au menu clic droit de Windows.

Personnalise ton menu clic droit sur Windows en utilisant le registre. Ce guide explique le principe, avec la méthode manuelle, le fichier .reg ou la ligne de commande, puis l'illustre avec trois exemples : ouvrir un dossier dans VS Code, copier un chemin complet, afficher l'arborescence.

01 · Les exemples

Trois exemples pour comprendre le principe

Le menu qui s'affiche quand tu fais un clic droit sur un dossier n'est pas figé : chaque entrée vient du registre de Windows, et tu peux en ajouter autant que tu veux. Le but est de comprendre le principe : on le met en pratique avec trois exemples, mais tu pourras ajouter n'importe quelle commande de la même façon.

ExempleCe qu'il faitCommande utilisée
Ouvrir dans VS CodeOuvre le dossier cliqué dans Visual Studio CodeCode.exe "%1"
Copier le chemin completMet dans le presse-papiers le chemin du fichier ou du dossiercmd /c echo | set /p="%1"| clip
Afficher l'arborescence (tree)Affiche tous les dossiers et fichiers du dossier cliquécmd.exe /k tree "%1" /a /f
Ces trois entrées ne sont que des exemples. Une fois le principe compris, tu peux ajouter n'importe quel programme ou n'importe quelle commande à ton menu clic droit, sans rien installer.
02 · Les bases

Le registre de Windows, c'est quoi ?

Le registre est la grande base de réglages de Windows. Beaucoup de programmes y stockent leurs paramètres, et c'est aussi là que Windows lit la liste des entrées du clic droit.

Comment il est organisé

  • Une clé ressemble à un dossier. Elle peut contenir d'autres clés.
  • Une valeur ressemble à un fichier : un nom et une donnée rangés dans une clé.
  • La valeur sans nom s'appelle (Par défaut). Dans un fichier .reg, on la note @.
  • On le consulte avec regedit : touche Win + R, tape regedit, Entrée.

Les types de valeurs utiles

TypeContenu
REG_SZDu texte simple (le plus courant ici)
REG_EXPAND_SZDu texte avec des variables comme %windir%, remplacées au moment de l'utilisation

Pour nos entrées, le texte simple (REG_SZ) suffit.

Les trois racines à connaître

RacineContenuDroits
HKEY_CLASSES_ROOT (HKCR)Associations de fichiers et menus clic droit, pour tous les utilisateursAdministrateur
HKEY_CURRENT_USER (HKCU)Réglages de ton compte uniquementUtilisateur normal
HKEY_LOCAL_MACHINE (HKLM)Réglages de toute la machineAdministrateur

HKEY_CLASSES_ROOT est une vue qui fusionne HKEY_LOCAL_MACHINE\Software\Classes et HKEY_CURRENT_USER\Software\Classes. Pour une entrée réservée à ton compte, sans droits administrateur, remplace HKEY_CLASSES_ROOT par HKEY_CURRENT_USER\Software\Classes dans tous les chemins de ce guide.

03 · Sécurité

Avant de toucher au registre

Une mauvaise modification du registre peut perturber Windows. Ce qu'on fait ici est peu risqué, à condition de respecter quelques règles.

Les bonnes habitudes

  • Sauvegarde la clé avant de la modifier : dans regedit, clic droit sur la clé > Exporter. Tu obtiens un fichier .reg que tu peux double-cliquer pour tout remettre.
  • N'ajoute que de nouvelles clés et ne modifie ou ne supprime que celles que tu as créées toi-même.
  • Utilise des noms de clés simples, sans accents ni espaces : OpenVSCode, CopyFullPath, ShowTree.
  • Lis chaque commande avant de la lancer : une entrée du clic droit exécute un programme quand on clique dessus.
Si tu as déjà créé des entrées à la main : utilise des noms de clés différents pour tester (par exemple OpenVSCode2), afin de ne pas écraser ce qui fonctionne déjà.
04 · Les emplacements

Où ajouter une entrée ?

Selon l'endroit où tu fais ton clic droit, Windows lit une clé différente. Dans chacune, on crée une sous-clé dans shell.

Les clés à connaître

Où tu cliquesClé du registreVariable
Sur un dossierHKEY_CLASSES_ROOT\Directory\shell%1
Dans le vide d'un dossier (arrière-plan)HKEY_CLASSES_ROOT\Directory\Background\shell%V
Sur un fichier (tous types)HKEY_CLASSES_ROOT\*\shell%1
Sur un lecteur (C:, D:…)HKEY_CLASSES_ROOT\Drive\shell%1
Fichiers et dossiers à la foisHKEY_CLASSES_ROOT\AllFilesystemObjects\shell%1

%1 et %V : le chemin cliqué

  • %1 est remplacé par le chemin complet de l'élément sur lequel tu as cliqué.
  • %V est remplacé par le dossier dans lequel tu te trouves, quand tu cliques dans le vide.
  • Mets-les toujours entre guillemets : "%1". Sans guillemets, un chemin contenant un espace serait coupé en deux.

Ta capture d'écran montre un clic droit sur un dossier : c'est la clé Directory\shell. Pour avoir les mêmes entrées quand tu cliques dans le vide d'un dossier ouvert, il faut aussi la clé Directory\Background\shell.

05 · Le principe

Anatomie d'une entrée de menu

Toutes les entrées du clic droit suivent la même structure : une clé pour l'entrée, et une sous-clé command pour ce qu'elle exécute.

La structure

HKEY_CLASSES_ROOT
└── Directory
    └── shell
        └── OpenVSCode                 <- nom interne (jamais affiché)
            ├── (Par défaut) = Ouvrir dans VS Code        <- le texte du menu
            ├── Icon         = ...\Code.exe,0             <- l'icône (facultatif)
            └── command
                └── (Par défaut) = "...\Code.exe" "%1"   <- la commande lancée
  • La clé OpenVSCode est le nom interne de l'entrée.
  • Sa valeur (Par défaut) est le texte affiché dans le menu.
  • La sous-clé command est obligatoire et s'écrit exactement comme ça. Sa valeur (Par défaut) contient la commande exécutée au clic.

Les valeurs facultatives

ValeurRôleExemple
IconAjoute une icône devant le texteC:\...\Code.exe,0 ou cmd.exe
PositionPlace l'entrée en haut ou en bas du menuTop ou Bottom
ExtendedCache l'entrée sauf si tu maintiens Maj en cliquantvaleur vide

Dans le texte du menu, un & souligne la lettre qui suit et en fait un raccourci clavier : E&xplorer s'affiche E<u>x</u>plorer. Utilise-le avec parcimonie.

06 · Méthode 1

Ajouter une entrée à la main avec regedit

C'est la méthode idéale pour comprendre. Pour l'exemple, on crée l'entrée « Ouvrir dans VS Code » pour un clic droit sur un dossier.

1

Ouvrir regedit

Appuie sur Win + R, tape regedit puis valide. Accepte la fenêtre de contrôle de compte d'utilisateur.

2

Aller à la bonne clé

Dans la barre d'adresse de regedit, colle Ordinateur\HKEY_CLASSES_ROOT\Directory\shell puis Entrée. Tu peux aussi descendre à la main dans l'arborescence de gauche.

3

Créer la clé de l'entrée

Clic droit sur shell > Nouveau > Clé, puis nomme-la OpenVSCode.

4

Définir le texte du menu

Sélectionne la clé OpenVSCode, double-clique sur la valeur (Par défaut) à droite, et saisis Ouvrir dans VS Code.

5

Créer la sous-clé command

Clic droit sur OpenVSCode > Nouveau > Clé, nomme-la exactement command.

6

Définir la commande

Sélectionne command, double-clique sur (Par défaut) et saisis :

"C:\Users\TON_NOM\AppData\Local\Programs\Microsoft VS Code\Code.exe" "%1"

Remplace TON_NOM par ton nom d'utilisateur Windows. Si VS Code est installé pour tous les utilisateurs, le chemin est plutôt C:\Program Files\Microsoft VS Code\Code.exe. Pour le retrouver : clic droit sur le raccourci VS Code > Propriétés > champ Cible.

7

Tester

Fais un clic droit sur un dossier : l'entrée doit apparaître immédiatement. Si ce n'est pas le cas, ferme et rouvre l'Explorateur de fichiers.

07 · Méthode 2

Ajouter une entrée avec un fichier .reg

Un fichier .reg contient tes entrées sous forme de texte. Un double-clic les ajoute, ce qui permet de refaire exactement la même chose sur un autre PC ou après une réinstallation.

La syntaxe d'un fichier .reg

Windows Registry Editor Version 5.00

[HKEY_CLASSES_ROOT\Directory\shell\ShowTree]
@="Afficher l'arborescence (tree)"
"Icon"="cmd.exe"

[HKEY_CLASSES_ROOT\Directory\shell\ShowTree\command]
@="cmd.exe /k tree \"%1\" /a /f"
  • La première ligne Windows Registry Editor Version 5.00 est obligatoire.
  • [chemin] désigne une clé (elle est créée si elle n'existe pas).
  • @="texte" définit la valeur (Par défaut).
  • "Nom"="texte" définit une valeur nommée, comme Icon.
  • Les lignes qui commencent par ; sont des commentaires.

Les caractères à doubler ou protéger

Dans le fichier .regValeur réelle dans le registrePourquoi
\\\Le backslash est un caractère spécial : on le double
\""Un guillemet à l'intérieur d'un texte doit être protégé par un backslash
Dans le fichier .reg :
@="\"C:\\Program Files\\Mon Appli\\app.exe\" \"%1\""

Valeur réelle dans le registre :
"C:\Program Files\Mon Appli\app.exe" "%1"

Utiliser le fichier

  1. Copie le texte dans le Bloc-notes, puis Fichier > Enregistrer sous.
  2. Choisis le type Tous les fichiers, un nom finissant par .reg (par exemple clic-droit.reg) et l'encodage Unicode (ou ANSI). Pas UTF-8, sinon les accents peuvent s'afficher de travers.
  3. Double-clique sur le fichier, confirme l'avertissement du registre et le contrôle de compte d'utilisateur.
  4. Fais un clic droit sur un dossier pour vérifier.

Pour modifier une entrée, clic droit sur le fichier .reg > Modifier : cela ouvre le fichier dans le Bloc-notes au lieu de l'appliquer.

08 · Méthode 3

Ajouter une entrée en ligne de commande (reg add)

La commande reg add crée des clés et des valeurs du registre directement depuis une invite de commandes. C'est pratique pour automatiser l'installation, par exemple dans un script .bat.

Avant de commencer

  • Pour écrire dans HKEY_CLASSES_ROOT, ouvre l'invite de commandes en administrateur : clic droit sur Invite de commandes > Exécuter en tant qu'administrateur. Sinon, tu auras « Accès refusé ».
  • Pour éviter l'administrateur, remplace HKEY_CLASSES_ROOT par HKEY_CURRENT_USER\Software\Classes dans les commandes.

La commande reg add

reg add "CLÉ" /ve /d "texte" /f
OptionRôle
/veCible la valeur (Par défaut) de la clé
/v NOMCible une valeur nommée, par exemple Icon
/t REG_SZType de la valeur : texte simple (c'est le type par défaut)
/d "données"Le contenu de la valeur
/fÉcrase la valeur si elle existe déjà, sans demander de confirmation

Si des clés du chemin n'existent pas encore, reg add les crée.

Exemple : « Ouvrir dans VS Code » sur un dossier

reg add "HKEY_CLASSES_ROOT\Directory\shell\OpenVSCode" /ve /d "Ouvrir dans VS Code" /f
reg add "HKEY_CLASSES_ROOT\Directory\shell\OpenVSCode" /v "Icon" /d "C:\Users\TON_NOM\AppData\Local\Programs\Microsoft VS Code\Code.exe,0" /f
reg add "HKEY_CLASSES_ROOT\Directory\shell\OpenVSCode\command" /ve /d "\"C:\Users\TON_NOM\AppData\Local\Programs\Microsoft VS Code\Code.exe\" \"%1\"" /f
  • Ligne 1 : crée la clé OpenVSCode et définit le texte du menu (sa valeur par défaut).
  • Ligne 2 : ajoute l'icône (valeur Icon).
  • Ligne 3 : crée la sous-clé command et y met la commande à lancer.
  • Dans la ligne 3, les guillemets à l'intérieur de la donnée sont protégés par un backslash : \". Comme dans un fichier .reg, c'est ce qui permet d'avoir des guillemets autour du chemin du programme.

Pour le clic dans le vide d'un dossier, refais les mêmes commandes avec Directory\Background\shell à la place de Directory\shell, et %V à la place de %1. Remplace aussi TON_NOM.

Pour retrouver le dossier de VS Code depuis le terminal : si la commande code fonctionne, where code affiche son emplacement, en général quelque chose comme ...\Microsoft VS Code\bin\code.cmd. Code.exe se trouve alors un dossier plus haut, dans ...\Microsoft VS Code\.

Vérifier ce qui a été créé

reg query "HKEY_CLASSES_ROOT\Directory\shell\OpenVSCode" /s

reg query affiche la clé, ses valeurs et ses sous-clés (/s descend dans les sous-clés). Tu y retrouves le texte du menu, l'icône et la commande.

Les deux autres exemples

reg add "HKEY_CLASSES_ROOT\Directory\shell\ShowTree" /ve /d "Afficher l'arborescence (tree)" /f
reg add "HKEY_CLASSES_ROOT\Directory\shell\ShowTree" /v "Icon" /d "cmd.exe" /f
reg add "HKEY_CLASSES_ROOT\Directory\shell\ShowTree\command" /ve /d "cmd.exe /k tree \"%1\" /a /f" /f

Pour « Copier le chemin complet », la commande contient des | et des guillemets imbriqués : elle est plus délicate à écrire dans l'invite de commandes. Pour celle-là, préfère le fichier .reg de la méthode 2.

Dans un fichier .bat : %1 devient %%1

Pour rejouer ces commandes sur un autre PC, enregistre-les dans un fichier .bat (par exemple installer-clic-droit.bat), puis lance-le avec clic droit > Exécuter en tant qu'administrateur.

@echo off
set "EXE=C:\Users\TON_NOM\AppData\Local\Programs\Microsoft VS Code\Code.exe"

reg add "HKEY_CLASSES_ROOT\Directory\shell\OpenVSCode" /ve /d "Ouvrir dans VS Code" /f
reg add "HKEY_CLASSES_ROOT\Directory\shell\OpenVSCode" /v "Icon" /d "%EXE%,0" /f
reg add "HKEY_CLASSES_ROOT\Directory\shell\OpenVSCode\command" /ve /d "\"%EXE%\" \"%%1\"" /f

pause
  • Dans un fichier .bat, chaque % doit être doublé : %1 s'écrit %%1, et %V s'écrit %%V. Sinon Windows remplace %1 par un argument du script, qui est vide.
  • set "EXE=..." range le chemin dans une variable, qu'on réutilise avec %EXE%. Un seul endroit à modifier.
  • pause laisse la fenêtre ouverte pour que tu puisses lire les messages.

Évite les accents dans un fichier .bat : l'invite de commandes ne les lit pas toujours correctement.

09 · Exemple 1

Exemple 1 : ouvrir un dossier dans VS Code

Premier exemple concret. Pour une autre application, il suffit de changer le texte du menu et le chemin du programme.

Le fichier .reg

Windows Registry Editor Version 5.00

; Clic droit SUR un dossier
[HKEY_CLASSES_ROOT\Directory\shell\OpenVSCode]
@="Ouvrir dans VS Code"
"Icon"="C:\\Users\\TON_NOM\\AppData\\Local\\Programs\\Microsoft VS Code\\Code.exe,0"

[HKEY_CLASSES_ROOT\Directory\shell\OpenVSCode\command]
@="\"C:\\Users\\TON_NOM\\AppData\\Local\\Programs\\Microsoft VS Code\\Code.exe\" \"%1\""

; Clic droit DANS le vide d'un dossier
[HKEY_CLASSES_ROOT\Directory\Background\shell\OpenVSCode]
@="Ouvrir dans VS Code"
"Icon"="C:\\Users\\TON_NOM\\AppData\\Local\\Programs\\Microsoft VS Code\\Code.exe,0"

[HKEY_CLASSES_ROOT\Directory\Background\shell\OpenVSCode\command]
@="\"C:\\Users\\TON_NOM\\AppData\\Local\\Programs\\Microsoft VS Code\\Code.exe\" \"%V\""

Remplace TON_NOM par ton nom d'utilisateur Windows (chemin installé pour ton compte), ou utilise C:\\Program Files\\Microsoft VS Code\\Code.exe si VS Code est installé pour tous les utilisateurs.

Ce que fait chaque ligne

LigneRôle
@="Ouvrir dans VS Code"Le texte affiché dans le menu
"Icon"="...Code.exe,0"L'icône : la première icône (numéro 0) contenue dans Code.exe
"...Code.exe" "%1"Lance VS Code en lui passant le dossier cliqué
"...Code.exe" "%V"Même chose, mais pour le dossier dans lequel tu cliques dans le vide

Il y a deux blocs : un pour le clic sur un dossier (%1), un pour le clic dans le vide d'un dossier (%V). Si tu n'as besoin que du premier, supprime le second.

10 · Exemple 2

Exemple 2 : copier le chemin complet

Deuxième exemple : cette entrée met dans le presse-papiers le chemin complet du fichier ou du dossier cliqué, par exemple C:\Users\toi\Documents\projet.

Le fichier .reg

Windows Registry Editor Version 5.00

; Clic droit SUR un dossier
[HKEY_CLASSES_ROOT\Directory\shell\CopyFullPath]
@="Copier le chemin complet"

[HKEY_CLASSES_ROOT\Directory\shell\CopyFullPath\command]
@="cmd /c echo | set /p=\"%1\"| clip"

; Clic droit SUR un fichier
[HKEY_CLASSES_ROOT\*\shell\CopyFullPath]
@="Copier le chemin complet"

[HKEY_CLASSES_ROOT\*\shell\CopyFullPath\command]
@="cmd /c echo | set /p=\"%1\"| clip"

; Clic droit DANS le vide d'un dossier
[HKEY_CLASSES_ROOT\Directory\Background\shell\CopyFullPath]
@="Copier le chemin du dossier"

[HKEY_CLASSES_ROOT\Directory\Background\shell\CopyFullPath\command]
@="cmd /c echo | set /p=\"%V\"| clip"

Comprendre la commande

cmd /c echo | set /p="%1"| clip
  • cmd /c : lance une commande dans une fenêtre invisible, puis la ferme.
  • set /p="%1" : affiche le texte %1 (le chemin) sans retour à la ligne à la fin.
  • echo | : fournit une entrée à set /p pour qu'il n'attende pas que tu tapes quelque chose.
  • | clip : envoie ce texte dans le presse-papiers (clip est un programme fourni avec Windows).

Pourquoi ne pas simplement écrire echo "%1" | clip ? Parce que echo ajoute les guillemets et un retour à la ligne à la fin. Avec set /p, tu obtiens le chemin tout propre, prêt à coller.

Entrée intégrée à Windows

Windows propose déjà Maj + clic droit > Copier en tant que chemin d'accès, mais le chemin copié est entouré de guillemets. Cette entrée personnalisée copie le chemin sans guillemets, en un seul clic droit, sans toucher à Maj.

11 · Exemple 3

Exemple 3 : afficher l'arborescence avec tree

Troisième exemple. tree est une commande Windows qui dessine l'arborescence d'un dossier : tous ses sous-dossiers et ses fichiers.

Le fichier .reg

Windows Registry Editor Version 5.00

; Clic droit SUR un dossier
[HKEY_CLASSES_ROOT\Directory\shell\ShowTree]
@="Afficher l'arborescence (tree)"
"Icon"="cmd.exe"

[HKEY_CLASSES_ROOT\Directory\shell\ShowTree\command]
@="cmd.exe /k tree \"%1\" /a /f"

; Clic droit DANS le vide d'un dossier
[HKEY_CLASSES_ROOT\Directory\Background\shell\ShowTree]
@="Afficher l'arborescence (tree)"
"Icon"="cmd.exe"

[HKEY_CLASSES_ROOT\Directory\Background\shell\ShowTree\command]
@="cmd.exe /k tree \"%V\" /a /f"

Comprendre la commande

cmd.exe /k tree "%1" /a /f
  • cmd.exe /k : ouvre une fenêtre d'invite de commandes et la laisse ouverte pour que tu puisses lire le résultat. Avec /c, elle se fermerait aussitôt.
  • tree "%1" : affiche l'arborescence du dossier cliqué.
  • /f : affiche aussi les fichiers, pas seulement les dossiers.
  • /a : utilise des caractères ASCII (|, +---) au lieu de traits graphiques. Le résultat reste lisible dans n'importe quelle police et se copie proprement dans un fichier texte.

Exemple de résultat (simplifié)

C:\MON-PROJET
|   index.html
|   style.css
|
+---css
|       main.css
|
\---img
        logo.png
Dossiers volumineux : sur un dossier qui contient des milliers de fichiers (par exemple node_modules), tree peut afficher des pages et des pages. Appuie sur Ctrl + C pour l'arrêter.

Variante : copier l'arborescence au lieu de l'afficher

@="cmd.exe /c tree \"%1\" /a /f | clip"

Avec /c à la place de /k et | clip à la fin, le résultat est envoyé dans le presse-papiers : pratique pour le coller dans un README ou dans la documentation d'un projet. Pour l'utiliser, crée une entrée supplémentaire (par exemple CopyTree) avec cette commande dans sa sous-clé command.

Windows 11

Sous Windows 11, le nouveau menu clic droit est plus court. Les entrées ajoutées par le registre n'y apparaissent pas directement : elles se trouvent sous Afficher plus d'options (ou avec Maj + F10). Le fonctionnement du registre est le même.

Sélection multiple

Si tu sélectionnes plusieurs éléments avant le clic droit, Windows peut lancer la commande une fois par élément (donc plusieurs fenêtres). Pour VS Code ou tree, mieux vaut cliquer sur un seul dossier à la fois.

13 · Annuler

Supprimer une entrée

Tu as le choix entre trois méthodes, de la plus visuelle à la plus rapide.

Avec regedit

Va dans la clé shell concernée, fais un clic droit sur la clé de l'entrée (par exemple OpenVSCode) > Supprimer. Ne supprime que tes clés, jamais shell elle-même.

Avec une commande

reg delete "HKEY_CLASSES_ROOT\Directory\shell\OpenVSCode" /f

À lancer dans une invite de commandes ouverte en administrateur. /f supprime sans demander de confirmation.

Avec un fichier .reg

Windows Registry Editor Version 5.00

[-HKEY_CLASSES_ROOT\Directory\shell\OpenVSCode]
[-HKEY_CLASSES_ROOT\Directory\Background\shell\OpenVSCode]
[-HKEY_CLASSES_ROOT\Directory\shell\CopyFullPath]
[-HKEY_CLASSES_ROOT\*\shell\CopyFullPath]
[-HKEY_CLASSES_ROOT\Directory\Background\shell\CopyFullPath]
[-HKEY_CLASSES_ROOT\Directory\shell\ShowTree]
[-HKEY_CLASSES_ROOT\Directory\Background\shell\ShowTree]

Le signe - devant le chemin signifie « supprime cette clé ». Enregistre ce texte dans un fichier .reg et double-clique dessus : toutes les entrées de ce guide disparaissent d'un coup.

14 · Dépannage

Problèmes fréquents

  • L'entrée n'apparaît pas. Vérifie que la sous-clé s'appelle exactement command, que tu as bien utilisé la bonne clé (Directory pour un clic sur un dossier, Directory\Background pour un clic dans le vide, * pour un fichier), puis ferme et rouvre l'Explorateur. Sous Windows 11, regarde sous « Afficher plus d'options ».
  • L'entrée apparaît mais rien ne se passe. Le chemin du programme est faux ou n'est pas entre guillemets. Teste la commande à la main dans une invite de commandes.
  • Une fenêtre noire s'ouvre et se ferme aussitôt. Tu as utilisé cmd /c : remplace par cmd /k pour garder la fenêtre ouverte.
  • Ça marche sur un dossier, mais pas dans le vide d'un dossier (ou l'inverse). Il manque le deuxième bloc : Directory\shell avec %1 d'un côté, Directory\Background\shell avec %V de l'autre.
  • Le chemin est coupé à un espace. Il manque les guillemets autour de %1 ou de %V.
  • Dans un fichier .bat, %1 ne fonctionne pas. Écris %%1 (et %%V) : chaque % doit être doublé.
  • Les accents s'affichent mal. Le fichier .reg a été enregistré en UTF-8 : enregistre-le en Unicode.
  • « Accès refusé » en modifiant HKEY_CLASSES_ROOT. Il faut les droits administrateur : lance regedit en administrateur, ou travaille dans HKEY_CURRENT_USER\Software\Classes.

Les fichiers .reg complets

Voici les fichiers des trois exemples. Copie-les dans le Bloc-notes, enregistre-les en .reg (encodage Unicode) et double-clique dessus. Pense à remplacer TON_NOM dans l'entrée VS Code.

"Icon"="C:\\Users\\TON_NOM\\AppData\\Local\\Programs\\Microsoft VS Code\\Code.exe,0"

Pour résumer

Une clé, un texte, une commande.

Chaque entrée du menu clic droit se résume à une clé dans shell, un texte affiché et une sous-clé command qui contient ce qui s'exécute. Une fois ce schéma compris, tu peux ajouter n'importe quel outil à ton menu, en gardant toujours un fichier .reg de secours pour l'annuler.
