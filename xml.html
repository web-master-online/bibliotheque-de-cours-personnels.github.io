01 · Les bases

À quoi sert le XML en Android ?

Le XML Android sert uniquement à décrire l'interface graphique : ce qui est affiché à l'écran, dans quel ordre, avec quelles tailles et quels styles.

Ce que fait le XML

  • Décrit la structure de l'écran
  • Place les conteneurs et les widgets
  • Définit les tailles et les styles

Ce que le XML ne fait pas

Le XML ne contient aucune logique. Il décrit la structure, exactement comme un fichier HTML décrit une page web. Le comportement (clics, calculs, données) est géré ailleurs, dans le code de l'application.

02 · Base

Structure de base d'un fichier XML Android

Une interface Android commence toujours par un conteneur principal. Tout ce qui est visible à l'écran est placé à l'intérieur.

<LinearLayout
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <!-- Les éléments de l'interface sont ici -->

</LinearLayout>
03 · Layout

Les conteneurs (layout)

Les conteneurs organisent les éléments à l'écran.

Les 4 conteneurs principaux

  • LinearLayout : empile les éléments (vertical ou horizontal)
  • ConstraintLayout : placement libre avec contraintes
  • FrameLayout : éléments superposés
  • ScrollView : contenu défilable

Exemple

<LinearLayout
    android:orientation="vertical">
    ...
</LinearLayout>
04 · Widgets

Les éléments visuels (widgets)

Chaque balise XML correspond à un élément visible.

Les widgets les plus courants

  • TextView : texte
  • ImageView : image
  • Button : bouton
  • EditText : champ de saisie
  • CheckBox : case à cocher
  • Switch : interrupteur
  • RecyclerView : liste dynamique
05 · Pratique

Exemple d'interface complète

<LinearLayout
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <TextView
        android:id="@+id/titre"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Titre de l'écran" />

    <ImageView
        android:id="@+id/image"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:src="@drawable/image_exemple" />

    <Button
        android:id="@+id/bouton"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Valider" />

</LinearLayout>
06 · À retenir

Règles importantes du XML Android

  • Chaque balise = un élément visible ou un conteneur
  • android:id identifie un élément
  • layout_width et layout_height sont obligatoires
  • Le XML ne fait que décrire l'interface
Une structure, pas une logique

Le bon objectif n'est pas de mémoriser chaque balise.

Il faut comprendre le rôle de chaque conteneur et de chaque widget. Une fois cette logique de structure comprise, construire n'importe quel écran devient un simple exercice d'assemblage.
